Overview


EcoRide is an open-source platform designed to enable sustainable ride sharing with real-time updates and transparent expense management. It provides a robust backend infrastructure and a responsive, map-based frontend to support eco-friendly transportation solutions.


Why EcoRide?
This project aims to simplify the development of eco-conscious mobility apps. The core features include:
🧩 🌐 WebSocket Communication: Facilitates real-time data synchronization between clients and server for seamless ride updates.
🏎️ 💰 Cost Logic Module: Calculates fair passenger contributions based on trip segments, distances, and fuel costs.
🗺️ 📖 Map Integration: Uses Leaflet within React to visualize routes, vehicle data, and live geographic updates.
⚡ 🚀 Fast Development Setup: Incorporates Vite, ESLint, and Tailwind for rapid, maintainable frontend development.
📊 📊 Analytics & Stats: Tracks environmental and financial savings, supporting sustainability insights.
